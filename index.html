⚠️ How to Save as PDF Correctly
1
Click 🖨️ Print PDF — the browser print dialog will open.
2
Under Destination, choose "Save as PDF".
3
Do NOT use Microsoft Print to PDF — it removes clickable links from your resume.
4
(Optional) Set Margins → None for the cleanest result.
✅ Best browser: Google Chrome gives the most accurate PDF output.
